# UX audit — 2026-08-16 (unattended session)

First systematic pass over the **live, human-facing surface** of the browser build. This is
the part of the project nothing automated has ever touched: the 30 replay traces, pixel
hashes and smoke tests all run through `validate` mode or scripted input, so menus, pause,
save/load and input edge cases have only ever been checked by hand, if at all.

Testing was done headlessly via the new `scripts/ux_probe.mjs` (no browser window, no audio),
so everything below is reproducible with a committed scenario file rather than a description
of what someone once clicked.

---

## Fixed

| What | Detail |
|---|---|
| **Every `Ctrl+<letter>` control was unreachable in the browser** | `web/index.html`'s `SCANCODE` map never listed letter keys, so the keydown handler returned early and they never reached the shared input buffer. Ctrl+A restart, Ctrl+G save, Ctrl+L load, Ctrl+R intro, Ctrl+S sound, Ctrl+Q quit, the Shift+letter cheats, Home/PageUp jumps and keypad movement were all dead. Fixed in `818d707`, verified end-to-end: Ctrl+A now restarts the level, which previously did nothing. |
| **Two plan docs stated the wrong status** | Plan 12's Phase 1 (Cargo feature gates) was marked ✅ done and was never built; plan 13's asset-manifest section still said "deferred" though it shipped in `2d5aec8`/`f48cec4`. Both corrected in `818d707`. |
| **No CI existed** | Added `.github/workflows/ci.yml` (`52d5784`) running `cargo xtask verify`, plus a second job that builds the C oracle from source — the gap `verify` structurally cannot cover. |

## Verified working (no action needed)

- **Pause menu**: opens, navigates, nested submenus (Settings → General, with help text),
  backs out, closes cleanly and resumes.
- **Quicksave/quickload round trip within one session**: F6 → Ctrl+A restart → F9 restores
  the saved position correctly.
- **OPFS persistence across a full browser restart**: `QUICKSAVE.SAV` survives at 3467 bytes
  in a reused profile. The reload-race fix (`a28cc21`) holds up.
- **Audio**: 400–650 buffers produced per run, no dropouts, no console errors.
- **Console cleanliness**: zero JS errors across every scenario run.

## Infrastructure gap found

Deciding finding #1 requires running the same save/load sequence natively and comparing. Two
things blocked that, one now fixed:

- **Fixed:** `scancode_from_key_name` (`seg009.rs`) knew only arrows, shift, space, enter and
  escape — no F6/F9, no Ctrl, no letters — so the native build could not be scripted through
  save/load at all. Extended in `52d5784`.
- **Still open:** the native build only writes state traces in `validate` mode. An
  interactive run driven by `POPTRACE_INPUT` produces no trace, so there is no way to assert
  on native game state during a scripted live session. Closing this would make the whole
  live surface differentially testable against the C oracle, the same way replays already are.

## Non-findings (checked, working as intended)

- **`Ctrl+G` appeared to do nothing** — correct: save game is only available on levels 3–13
  (`README.upstream.md:204`), and the test was on level 1. Nearly logged as a bug.
- **`PRINCE.SAV` / `PRINCE.HOF` are 0 bytes in OPFS** — empty placeholders created by the
  persistence layer, not evidence of failed writes.

## Assumptions made

1. **Mapped only the keys the game actually binds**, not all of A–Z, so unmapped keys fall
   through without `preventDefault` and browser shortcuts the game doesn't use (Ctrl+W/T/N)
   keep working. The alternative — mapping everything — would hijack them.
2. **Left the existing F1–F12 mappings alone**, including F5 and F11, even though the game
   only binds F6/F9/F12. Narrowing them would restore browser reload / fullscreen but changes
   behavior that predates this session.
3. **Did not push.** CI is committed but has never run; it cannot be verified without a push,
   and `origin` is behind local `master`.
4. **Stopped investigating finding #1** rather than guessing at a fix, on the grounds that a
   wrong "fix" to faithful behavior is worse than an open ticket.
